# RasCAL-2

RasCAL-2 is a software for the analysis of multi-contrast neutron reflectometry data. it  is the successor 
to the original RasCAL software and the graphical user interface (GUI) for the Reflectivity Algorithm Toolbox 
(https://github.com/RascalSoftware/python-RAT).
